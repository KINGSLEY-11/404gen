# HARMATTAN FARE

A dusk-shift keke run through a laterite Enugu street.

Tap **START SHIFT**. Left stick drives (up = forward). Pull up beside a hailing passenger to board, then drop them on the gold ring. Horn if you need to call them. Don't hit the goats.

Every 3D object is a Three.js module. No meshes, no textures, no downloads.

## Play locally

```bash
python3 -m http.server 8080 --directory .
```

Open `http://localhost:8080`.

## Jam

Built for the 404 Game Jam (11–25 Sep 2026) from the 404-game-recipe contract.
The find: a fare-meter taxi loop on a harmattan compound street — two colour temperatures, boarding/drop-off as the verb, goats as the traffic — instead of a circuit racer or a shooter.
